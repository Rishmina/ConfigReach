Codecov for configuration space.

Your tests may cover the code while still missing the configuration states that change its behavior. ConfigReach deterministically finds environment variables, feature flags, settings, deployment configuration, values, branches and combinations — then maps them to test evidence.

Quick start

Install from PyPI and scan locally.

ConfigReach 0.9.1 supports Python 3.11+ and keeps the core completely model-free and dependency-free at runtime.

configreach — local CLI
$ python -m pip install --upgrade configreach
$ configreach scan .
$ configreach coverage .
$ configreach matrix .
$ configreach diff origin/main...HEAD
